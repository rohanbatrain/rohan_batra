# Quickstart: Book Creation System

1) Create a Book (Admin)
- Go to Admin → Books → New
- Enter title, language, optional series/subtitle/cover; Save as Draft

2) Add Chapters
- From the Book page, click “Add Chapter”; enter title; Save (draft)
- Reorder chapters via drag or order inputs
- Write in the editor; markdown paste converts to rich text; autosave

3) Link Characters (optional)
- In Book → Characters tab, add existing characters and specify roles

4) Publish
- Publish selected chapters when ready
- Set book status to Published once minimum chapters are ready

5) Public View
- Visit /books to see published books
- Open a book to see its metadata and published chapters

6) Settings
- Admin → Settings: set default timezone, default book/chapter visibility, enable analytics
